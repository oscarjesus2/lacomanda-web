Configuración de impresión

Prepara QZ Tray para imprimir desde LaComanda

Esta configuración se realiza una sola vez en cada ordenador que vaya a imprimir. Descarga los tres recursos y sigue el orden indicado.

info

QZ Tray debe permanecer abierto durante la jornada. No es compatible con móviles ni tabletas.

  1. 1
    download

    Descarga e instala QZ Tray

    Abre la página oficial, elige el instalador para Windows o Linux y conserva las opciones recomendadas.

    open_in_new Descargar QZ Tray
  2. 2
    verified_user

    Descarga el certificado de LaComanda

    Después de instalar QZ Tray, agrega certificate.pem desde Advanced > Site Manager.

    workspace_premium Descargar certificado
  3. 3
    picture_as_pdf

    Consulta el manual ilustrado

    Incluye el recorrido completo para Windows y Linux, la importación del certificado, la prueba final y soluciones rápidas.

    download Descargar manual PDF
check_circle
Cuando termines

Deja QZ Tray abierto, vuelve a LaComanda y actualiza la página para comprobar la conexión.
